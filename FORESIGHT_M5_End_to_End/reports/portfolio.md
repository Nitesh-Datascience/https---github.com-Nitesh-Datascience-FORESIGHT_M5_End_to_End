# Portfolio Description

**FORESIGHT — Real-World Demand Forecasting & Inventory Risk Intelligence**

Built an end-to-end retail analytics solution using real M5 sales, calendar and price data. The system compresses the large source data into a deployment-friendly 120-series dataset, engineers leakage-safe time-series features, benchmarks machine learning against a seasonal-naive baseline, forecasts the next 28 days, evaluates predictions against an official held-out future period, and presents business actions through Streamlit.

**Stack:** Python, Pandas, NumPy, Scikit-learn, Plotly, Streamlit, FastAPI.

**Key result:** 28.82% backtest WAPE vs 36.19% seasonal-naive baseline; 33.13% WAPE on the official 28-day held-out period for the compact 120-series evaluation.
